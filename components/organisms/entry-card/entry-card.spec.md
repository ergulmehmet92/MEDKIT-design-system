# mk-entry-card

**Purpose:** A build-log entry or design iteration.
**Atomic level:** Organism. **Status:** Ready. Matches `Cards`.

Props: `title`, `href`, `date`, `added`, `removed`, `version` (a version Badge), `status` (a StatusPill), `kind` ("Build log" or "Iteration"), `titleAs`. Changes list in the label face: added lines start with a honey plus, removed lines with a muted minus, and each reads "Added:" or "Removed:" to screen readers.

**Contains:** Card, Badge. **Used in:** the portfolio's build log.
