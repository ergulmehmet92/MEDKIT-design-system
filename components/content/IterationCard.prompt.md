A single frame in a design-iteration / creative-exploration gallery. Pairs with `VersionBadge`.

```jsx
<IterationCard
  label="Compact toolbar"
  version="v3"
  status="current"
  current
  note="Collapsed secondary actions into an overflow menu."
  art="linear-gradient(135deg,#20262a,#0c0c0c)"
/>
```

Set `current` to mark the chosen iteration (craft-accent border). `art` takes an image URL or CSS background. Lay several out in a grid to show the progression v1 → v3.
