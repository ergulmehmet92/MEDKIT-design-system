Thumbnail card for video / YouTube content. 16:9 cover with duration badge and a play affordance on hover.

```jsx
<VideoCard
  title="Designing an AI annotation tool in 12 weeks"
  channel="Mehmet Ergul"
  meta="24K views · 2 weeks ago"
  duration="14:22"
  thumb="linear-gradient(135deg,#241f1a,#0c0c0c)"
  badge="New"
/>
```

`thumb` takes an image URL or any CSS background. Lay out in a responsive grid.
