# mk-pull-quote

**Purpose:** A quote that stops the reader.
**Atomic level:** Molecule. **Status:** Ready. Matches `Cards`: type alone, no marks or shapes.

Props: `children` (the quote, without quotation marks), `attribution`, `source`, `size` (`"short"`, `"medium"` or `"long"`; by default up to 28 characters is short and over 140 is long), `cite`. A `blockquote` in a `figure`, with the attribution in a `figcaption` in the label face. Sizes scale with the quote's container.

**Contains:** nothing. **Used in:** case studies and posts.
