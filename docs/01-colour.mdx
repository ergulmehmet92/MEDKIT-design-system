# Colour

A small palette, each colour with one job. Components read **roles**, never raw colours, so a role can change in one place. Every role is written once with `light-dark()`, so Forest and Paper come from the same token; in forced colours each role maps to a system colour.

## Status

Status colours report whether something works, and nothing else. They always sit beside a word, in a StatusPill, and never stand alone.

## Rules

- One accent: honey marks the single thing to notice in a view.
- Text never sits on a colour that fails 4.5:1; large type and marks need 3:1. `npm run contrast` checks every pair.
- No new colours outside the palette: new needs are met with roles over the colours above.
